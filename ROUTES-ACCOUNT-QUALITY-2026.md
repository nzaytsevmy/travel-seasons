# Маршруты и учётная запись: контракт качества 2026

Цель релиза — дать читателю полезный план поездки без регистрации и создать
измеримый, но ненавязчивый путь к подходящему партнёрскому предложению.
Оценка «10/10» допустима только по заранее заданным критериям ниже, а не по
впечатлению от интерфейса.

| № | Критерий | Обязательный гейт |
|---:|---|---|
| 1 | Польза | Даты, состав, порядок и набор остановок меняются; результат сохраняется и восстанавливается. |
| 2 | Редакционное качество | Каждый маршрут основан на опубликованном материале; источник и дата проверки видны. |
| 3 | SEO | Хаб индексируется; производные маршруты закрыты от индекса и sitemap до проверки спроса, уникальности и каннибализации. |
| 4 | Монетизация | Один релевантный CTA, честная подпись, проверенный deep link, disclosure и `rel=sponsored`. |
| 5 | Измеримость | События проходят whitelist; в аналитику не уходят точные даты, идентификаторы и содержимое плана. Деньги оцениваются только по зрелой approved-выручке. |
| 6 | Приватность | Локальный режим без входа; облако только по отдельному согласию; базовый профиль Яндекс ID описан без ложных обещаний. |
| 7 | Безопасность | OAuth Code + PKCE + state, Secure HttpOnly cookie, CSRF, точный CORS, лимиты, идемпотентность, безопасные логи и секреты в Lockbox. |
| 8 | Целостность данных | Не более 20 планов, нет тихой потери, конфликт не перезаписывается автоматически, есть «облачная версия» и «сохранить обе». |
| 9 | Контроль пользователя | Есть экспорт, выход и удаление облачной учётной записи; локальная и облачная копии явно различаются. |
| 10 | Доступность | Клавиатура, статусы для screen reader, подписанные элементы и зоны нажатия не меньше 44 px. |
| 11 | Mobile и визуал | Нет горизонтального переполнения на 402 px и десктопе; критические состояния проверены реальным браузером. |
| 12 | Эксплуатация | Staging перед production, immutable image, readiness/health checks, бюджет, алерты, rollback и независимая live-проверка. |

## Что означает готовность

- **Локальный продукт готов к публикации**, когда сборка, SEO, монетизация,
  delivery, backend unit-тесты и браузерная регрессия зелёные, а live-страницы
  проверены после деплоя.
- **Облако готово к включению**, только когда на staging пройдены реальный вход
  Яндекс ID, перенос в обе стороны, конфликт, 20/21 план, истечение сессии,
  экспорт, удаление, восстановление из резервной копии, бюджетный алерт и откат.
- **Рост монетизации доказан**, только после созревшего рандомизированного
  эксперимента по правилам `MONETIZATION-2026.md`; клики и сохранения — ведущие
  диагностические сигналы, не доход.

До выполнения последнего пункта облачная кнопка остаётся выключенной флагом
`PUBLIC_ROUTE_SYNC_ENABLED=false`. Это штатное состояние, а не скрытая
недоделка.
