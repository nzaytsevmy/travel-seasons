## Топ находок

**🟠 P2 — новая:**
- `calculator-cheapest-month-wrong-case` — на `/calculator/` в состоянии по умолчанию
  (месяц «Любой» — исходный вид страницы для КАЖДОЙ страны, до выбора конкретной даты)
  подсказка выводит «Самый дешёвый месяц — июне» вместо грамматически верного
  «...— июнь» (падеж не согласован). Причина: `MONTH_FULL` (`calculator.astro:69`) —
  массив предложного падежа, задуманный для фразы с предлогом «в» (и так и
  используется в соседней ветке — «В <strong>июне</strong> на 15% дешевле»,
  `calculator.js:156`), а строка `:158` берёт тот же массив для конструкции через
  тире, которая требует именительный падеж без предлога. Текст рождается только в
  клиентском JS после расчёта на живой странице — в SSR HTML фразы нет (проверено
  прямым fetch без выполнения JS: 0 совпадений), поэтому статический скан `dist/`
  этого не ловит принципиально — только живой клик/загрузка калькулятора. Живьём:
  прогнаны все 77 направлений через `#calcRegion` в стартовом состоянии — 77 из 77
  попали в кейс с ошибкой падежа, 0 — в грамматически верную ветку «В X на N%
  дешевле» (та требует, чтобы пользователь заранее выбрал месяц И экономия была >5% —
  с текущими ценами такого не нашлось ни на одном направлении). То есть баг виден
  практически на каждой первой загрузке страницы для каждой страны, не в редком углу.
  Примеры: Египет → «...— июне», Кения/Мадагаскар/Танзания → «...— марте», Катар →
  «...— октябре», ОАЭ/Саудовская Аравия → «...— мае» — ошибка систематическая по всему
  массиву дат, не опечатка в одном месте. Скрин
  `radar/assets/calculator-cheapest-month-wrong-case.png`. Фикс одной строкой без
  нового массива данных: `Дешевле всего — в <strong>${monthName}</strong>` вместо
  `Самый дешёвый месяц — <strong>${monthName}</strong>` (`calculator.js:158`) —
  согласуется с тем, как `MONTH_FULL` уже используется в соседней ветке.

- **Функциональность калькулятора после рефакторинга** — смена уровня комфорта

  без ошибок.
- **Липкое меню на главной при прокрутке (новое, `#655`)** — @1280 после скролла на
