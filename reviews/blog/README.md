# Артефакты независимой оценки статей

Один файл на статью: `reviews/blog/<slug>.json`. Ссылка на него — в шапке статьи (`reviewRef`),
рядом `authoredBy`. Гейт `scripts/article-review-gate.mjs` требует артефакт у статей, сверенных
(`reviewed`) с 03.09.2026, и валит заявку, если рецензент совпадает с автором или оценки в шапке
не совпадают с оценками рецензента число в число. Автор свою статью не оценивает.

```json
{
  "schemaVersion": 1,
  "slug": "ostrov-valaam-2026",
  "reviewer": "claude-opus-independent-review",
  "reviewedAt": "2026-09-04",
  "qualityScore": { "topic": 10, "facts": 9.5, "visuals": 9, "experience": 6, "internalLinks": 10, "legal": 10, "overall": 9.1,
    "ceiling": "До 10 не хватает личной поездки автора и зрелых результатов страницы" },
  "rationale": "Что сверено, что найдено и исправлено, почему такой потолок — не короче 40 знаков.",
  "risks": ["что может протухнуть и когда пересверить"],
  "proseHash": "хеш текста статьи: node scripts/article-review-gate.mjs hash src/content/blog/<slug>.mdx"
}
```

Порядок: автор дописал → рецензент прочитал ИМЕННО эту версию, посчитал хеш, положил оценки и хеш в
артефакт → автор перенёс оценки в шапку, поставил `reviewed` (не раньше 03.09.2026). Любая правка текста,
заголовка или описания после оценки меняет хеш,
и гейт краснеет до повторной оценки. Честный потолок гейта: он доказывает, что артефакт относится к этому
тексту и подписан другим именем, а не то, кто на самом деле думал, — имена самодекларируемы.
