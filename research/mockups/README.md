# Три макета страницы раздела

Сделаны 28.08.2026 по `../section-page-format.md`. Живые файлы с настоящими
данными: 74 направления, цены недели считаются как на главной и в калькуляторе.
Поиск и одиннадцать кнопок отбора работают, счётчики живые.

- `a.html` — **Реестр**: документ с регистрационным номером, ответ и оттиски
  сверху, инструмент ниже.
- `b.html` — **Инструмент сверху**: подпись, поиск, кнопки отбора и сводка
  числами в одной рамке; реестр сразу под ней, справка в конце. **Выбран
  Никитой и перенесён на страницу виз.**
- `v.html` — **Дневник**: язык главной, полки со снимками, реестр приложением.

`собрать.mjs` пересобирает все три из `visa-data.json`, который делается из
данных сайта. Держать здесь, чтобы следующий раздел не изобретали заново.

⛔ Серые прямоугольники в «Дневнике» — заглушки вместо снимков.
