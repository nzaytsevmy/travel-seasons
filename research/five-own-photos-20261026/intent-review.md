## Рекомендуемые title, description и первые абзацы

Это конкретные редакторские варианты для владельца текста; в MDX ничего не менял. Их применение требует соответствующей содержательной правки из `prose-review.md`.

### США

- **Title:** «Зайон, Брайс и Хорсшу-Бенд: маршрут на машине». Текущий «Юта и Аризона: Зайон, Брайс-Каньон и Хорсшу-Бенд» уже достаточно узок; менять его ради формального отсутствия дубля необязательно. Добавление «маршрут» оправдано после появления фактической схемы.
- **Description:** «Как связать Зайон, Брайс-Каньон и Хорсшу-Бенд: базы для ночёвок, прогулки разной сложности, шаттлы и отдельная парковка у Пейджа».
- **Lead:** сразу дать выбранный порядок и число баз, затем выбор простой/длинной прогулки. После подтверждения аэропортной рамки — срок предложенного отрезка. Не начинать с общего «несколько характерных мест США»; не добавлять новые личные даты/прохождения.
- **Разделение с хабом:** страновой FAQ оpass остаётся на хабе; здесь нужна применимость к двум конкретным паркам и отдельной муниципальной парковке. Узкая необходимая информация о допсборе не считается вредным дублем: без неё маршрутный бюджет будет неполным.

## Перелинковка и скрытая развилка шаблона

1. Хабы выводят `RELATED_POSTS[slug]` из `src/data/related-posts.js` через `directions.js:362`. На момент чтения отдельных записей для usa/norway/iceland/brazil там не найдено; одно наличие `destinations` вMDX не доказывает входящую ссылку из хаба.
2. Для этих четырёх узких статей подходит `kind: 'practical'` и точный маршрутный анкор. **Не присваивать автоматически `kind: 'guide'`.** `deepGuide = d.relatedPosts?.find(p => p.kind === 'guide')` в `[slug].astro:233` включает другой title/description хаба и видимую строку «Полный гайд». Узкий Trolltunga/Lofoten или São Paulo не является полным гидом по стране. `practical` уже используется в проекте для подробных материалов по отдельным местам.
3. Ссылку из хаба ставить в «Подробные гайды» и по возможности у соответствующего выбора: USA — Юго-Запад; Norway — Trolltunga/Lofoten; Iceland — Golden Circle; Brazil — отдельная городская остановка/прибытие вSãoPaulo. Не расширять ради ссылки весь страновой текст.
4. Обратную ссылку статьи направить на соответствующий хаб для общестрановой рамки. Для Norway ссылка требует осторожности из-за отдельно названного правового риска ниже; не отправлять читателя за гарантией въезда к непроверенной категоричной фразе. КаноническиеURL статей сохранять собственными; оснований склеивать с хабами черезcanonical/redirect по этому сравнению нет.

## Намибия: не создавать ссылку из грамматического словаря

В `directions.js` есть грамматическая запись `COUNTRY_CASES['namibia']`, но в `regions.js` нет соответствующего направления; `DIRECTIONS` создаётся обходом именноregions, затем `getStaticPaths()` генерирует изDIRECTIONS. Также целевой объект Namibia вcountry-guides не найден. Поэтому наличие падежей само по себе **не создаёт `/namibia/`**. Не вставлять такую ссылку без самостоятельного подтверждения существующего маршрута/страницы. Это уточняет прежний список кандидатов G4 вprose-review: там прямо требовалась проверка существования, теперь уNamibia она не пройдена. Для новой узкой статьи конкурирующий страновой хаб в рассмотренной цепочке не обнаружен; это не глобальный аудит всехURL сайта.

## Отдельный риск: юридическая категоричность хаба Norway

В `country-guides.js` подозрительная конструкция повторяется вgetThere, practical, dataNote иFAQ; она сводит въезд к единственному способу через другую шенгенскую страну и обобщает отсутствие выдачи виз. В `hub-snippets.js:31` при этом более узкийtitle про въезд, аdescription говорит о туристическом запрете и исключениях. Значит, источник/сниппет/видимый текст не дают согласованного юридического объяснения. Это риск существующего хаба, **не правило для переноса в новый гайд**; файл не редактировался.

Чтобы не объявлять подозрение доказанной ошибкой, отдельно открыта [актуальная страница UDI](https://www.udi.no/en/information-ukraine-and-russia/information-for-russian-nationals/) 26.10.2026: она различает туристические/иные цели и исключения, содержит отдельное положение о прибытии из другой страны Шенгена. Следовательно, тезис «любой такой переход запрещён» также не подтверждён. Проблема — категоричное «только» и стирание условий/исключений, а не доказанная ложность самого упоминания внутреннего прибытия. Эта заметка не является персональным советом о допустимости въезда или маршруте оформления визы. Для исправления хаба нужен отдельный адресный фактчек основания поездки/типа документа и актуальной редакции официальных правил, без расширения текущего задания на редактуру хаба.

**Критерий следующей проверки:** каждый новыйURL даёт свой законченный путь читателю; Norway/Iceland получают конкретику поверх уже имеющегося обзора; входящие анкоры называют узкую задачу; `kind` не включает ложное «Полный гайд»; новая проза не копирует непроверенную юридическую формулировку старого хаба. Позиции/показыURL по общим запросам измеряются отдельно после выпуска.
