# Очередь гайдов и маршрутов TravelTribe

Это отдельная очередь глубоких материалов для задачи понедельник/среда/пятница
14:00. Обычные статьи, новости и брендовые обзоры сюда не попадают. Радар
поискового роста может добавить не более одной измеренной строки за запуск;
недельный контролёр определяет, какая открытая строка получает приоритет.

Пустая очередь не является причиной для `HOLD`: она запускает `QUEUE_RECOVERY`
по профильному промту. Ждать следующего радара без полной сверки нельзя.

## Типы задач

- `NEW_GUIDE` — новый полный гайд с отдельным подтверждённым интентом.
- `NEW_ROUTE` — новый физически выполнимый маршрут по дням с картой.
- `REVISE_GUIDE` — существенная доработка существующего канонического URL.
- `HOLD` — публикация запрещена до выполнения записанного условия.

После полной сверки её заменяет верхний прошедший кандидат либо доказательный
`HOLD` с реестром всех проверенных кандидатов.

## Реестр покрытия кандидатов

Каждый запуск `QUEUE_RECOVERY` добавляет одну строку на каждый найденный
кандидат. Допустимы только итоги `принят / отклонён / отложен`; ни один кандидат
из семантического ядра, последних радаров, очереди или существующих URL не
пропускается без записи.

| Дата | Кандидат и источник | Целевой URL / тип | Проверенные сигналы | Итог | Причина или недостающее | Следующая проверка |
|---|---|---|---|:---:|---|---|
| — | Реестр ещё не сформирован | — | — | `QUEUE_RECOVERY` | Это пробел процесса, а не доказательство отсутствия тем | Ближайший запуск контура |

Контроль полноты обязателен: `найдено = принято + отклонено + отложено`. Если
равенство не сходится или кандидат не получил исход, очередь считается
непроверенной и публикация не начинается.

Новая строка обязана содержать дату замера, окна, целевой URL, тип, отличие от
существующих страниц, источник спроса, достижимость выдачи, доступность
первоисточников и изображений. Один запуск закрывает одну верхнюю открытую строку.

Задача снимается только после зелёного полного CI, merge, deploy и проверки
живого URL на 402 и 1280 px, карты/маршрута, canonical, внутренних ссылок и
денежного пути. Черновик, коммит и открытый PR завершением не считаются.
