## Дублирование

Эти напоминания продублированы в:
1. **Google Calendar** (5 SEO + 2 weekly content recurring) — главный канал, email+popup
2. **macOS Reminders.app** (синк с iCloud → iPhone)
3. **REMINDERS.md** (этот файл, в репо)

В каждом напоминании — **готовый промпт** который можно копировать и вставить в Claude Code.

## Как пользоваться напоминанием

1. Получил email/popup
2. Открой Calendar event или Reminders.app, скопируй текст description
3. Открой Claude Code: `cd ~/seasons-work && claude`
4. Вставь текст промпта (между `═══`)
5. Claude действует по промпту → ты подтверждаешь решения

Промпты составлены так, что Claude получает полный контекст + список действий + ожидаемый формат результата. Качество 10/10 если следуешь без отклонений.

## Если что-то не сработало

- **Не пришло email/popup** — открой `~/seasons-work/REMINDERS.md` вручную, там даты
- **Промпт не подошёл (хочешь другое)** — скажи Claude «давай другую задачу из CONTENT-PLAN.md»
- **Пропустил неделю** — Claude автоматически возьмёт следующий неиспользованный слот, не нужно догонять
